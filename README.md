# Algoryx Internship — Task 3
## Interactive 3D Web Experience

This React/Vite project is structured around an Algoryx Community 3D asset and uses Three.js + React Three Fiber for browser-based interaction.

### IMPORTANT — add your Algoryx Community asset
Download the assigned/selected `.glb` asset from the Algoryx Community and save it exactly as:

`public/algoryx-community-asset.glb`

The code already points to that filename.

### Run
```bash
npm install
npm run dev
```

### Build
```bash
npm run build
```

### Tech
React, Vite, Three.js, React Three Fiber, React Three Drei, WebGL.
